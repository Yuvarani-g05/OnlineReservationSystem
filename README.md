# Online Reservation System

## 📌 Project Overview

The Online Reservation System is a Java-based desktop application developed to simplify train ticket reservation and cancellation. It allows users to enter passenger details, book train tickets, and manage reservations through a graphical user interface.

This project was developed as part of the **Java Development Internship at Oasis Infobyte (OIBSIP)**.

## 🎯 Objective

The main objective of this project is to develop a simple and user-friendly railway reservation system using Java Swing and SQLite database connectivity.

## ✨ Features

* **Train Reservation:** Enter passenger and journey details to book a train ticket.
* **Train Details:** Retrieve the train name using the train number.
* **PNR Generation:** Generate a unique PNR for a reservation.
* **Ticket Cancellation:** Cancel an existing reservation.
* **Database Management:** Store and manage reservation information using SQLite.
* **Graphical User Interface:** Interact with the application through Java Swing forms.

## ⚙️ Project Setup

### Prerequisites

* Java Development Kit (JDK)
* Eclipse IDE or another Java IDE
* SQLite JDBC Driver

### Steps to Run

1. Clone or download this repository.
2. Open Eclipse IDE.
3. Import the project into Eclipse.
4. Ensure that the SQLite JDBC driver is added to the project's build path.
5. Check that the database is initialized and the required tables and train records are available.
6. Run the main application class.
7. Enter the required details to test the reservation system.

## 🗄️ Database

The project uses an SQLite database named `reservation.db`.

The database setup includes tables for:

* Users
* Trains
* Reservations

The database stores the information needed for user management, train details, and ticket reservations.
